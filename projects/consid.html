Consid Internship

Built an internal UEFA Euro 2024 prediction app as a frontend developer and UI/UX designer at Consid AB, Jönköping.

Role Frontend Developer & UI/UX Designer
Client Consid AB, Jönköping
Tools Figma · Next.js · React · Tailwind CSS · Azure DevOps
Year 2024

Project Overview

During my internship at Consid AB I worked as a Frontend Developer and UI/UX Designer in a team of four interns. Our task was to build an internal web application where employees could predict match results during the UEFA Euro 2024 tournament.

We built the app using Next.js, React, and Tailwind CSS, with .NET handling the backend. The goal was to create a responsive and user-friendly platform that made it easy for employees to register and track their predictions throughout the tournament.

My Contributions

Navigation & Layout

  • Developed the navigation bar and footer based on a Figma design.
  • Implemented responsive design for both desktop and mobile views.
  • Created an interactive hamburger menu and hover states with Tailwind CSS.
  • Collaborated with supervisors to follow best coding practices and component-based structure.

Group Stage Component

  • Designed and coded a group stage view displaying matches, flags, dates, and score input boxes.
  • Integrated data dynamically from an API and handled error debugging.
  • Ensured a responsive and accessible layout for all screen sizes.

Validation & Logic

  • Implemented input validation to ensure prediction fields were filled correctly.
  • Added error messages and red borders for empty fields, improving UX feedback.
  • Connected the logic so that user predictions update the live standings table in real time.

About Page & Metadata

  • Created an About page using Markdown integrated into Next.js.
  • Designed a favicon and improved page metadata; title, description, and OG image, for better accessibility and sharing.
